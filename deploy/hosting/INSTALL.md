# 榕光評測平台：獨立安裝包安裝說明（Hostinger Node.js 託管）

這個安裝包是一個完整的網站：前端畫面（`public/`）和後端（`src/`）由同一個 Node.js 程式提供，
資料存在一個 SQLite 檔案裡，不需要另外裝資料庫。

## 0. 先確認你的方案

- 需要 Hostinger 的 **Node.js 應用託管**（通常是 Business 或 Cloud 類型的 Web Hosting，面板裡會有
  「Node.js」或「網站應用」選項），或是 **VPS**。入門的共享方案沒有 Node.js，無法執行這個安裝包。
- Node.js 版本要選 **22 或以上**（資料庫元件在較舊的版本會當掉）。
- 網站一定要有 **HTTPS**（登入用的 cookie 在正式模式要求 HTTPS）。

> Hostinger 的面板介面與選項名稱可能隨時調整，以下用「意思」描述，請對照你看到的畫面。

## 1. 上傳與解壓縮

1. 在 hPanel 建立一個 Node.js 應用（選你要用的網域或子網域）。
2. 用「檔案管理員」把 `ai-assessment-installer-xxxx.zip` 上傳到該應用的根目錄並解壓縮。
   解壓後應用根目錄要直接看到 `package.json`、`src/`、`public/`（不要多包一層資料夾；多包了就把裡面的東西移上來）。

## 2. 設定應用

| 項目 | 填什麼 |
|---|---|
| Node.js 版本 | 22 或以上 |
| 應用根目錄 | 解壓縮的位置 |
| 啟動檔 / Entry file | `src/server.js`（或啟動指令 `npm start`） |
| 安裝相依套件 | 面板上的「NPM install」，或終端機執行 `npm ci --omit=dev` |

## 3. 環境變數（最重要）

照 `.env.example` 逐項填進面板的 Environment variables。**必填：**

- `JWT_SECRET`：至少 32 字元的隨機字串，自己用密碼產生器產生，不要與他人共用。
- `ADMIN_EMAIL`、`ADMIN_PASSWORD`：第一位管理員的帳號密碼。請設一組只有你知道的強密碼。
- `NODE_ENV=production`
- `STATIC_DIR=./public`
- `DB_PATH`：資料庫位置，見下一節。
- `APP_URL`：你的網站網址。
- `TRUST_PROXY=1`

面板不能設環境變數時，把 `.env.example` 複製成 `.env`，填好後放在應用根目錄（這個檔不要外流）。
寄信與 AI 小幫手是選填，沒填就自動停用，其他功能照常。

## 4. 啟動

按面板的「啟動 / 重新啟動」。打開你的網址應看到首頁；登入頁用上面設定的管理員帳號登入。
網址後面加 `/api/health` 應回傳 `{"ok":true,...}`，可用來確認後端有起來。

## 5. 資料庫與備份（請務必看）

- 所有資料（帳號、作答、班級）都在 `DB_PATH` 指向的檔案旁（實際檔名是該路徑加上 `.sqlite3`）。
- **有些託管在重新部署、更新程式時會清空應用資料夾。** 為了避免資料被清掉，建議把 `DB_PATH` 設在
  應用資料夾**外面**、你的帳號底下的另一個資料夾，例如 `/home/你的帳號/ai-assessment-data/db.json`
  （資料夾要先建立，且 Node 程式有寫入權限）。
- 備份：定期把 `db.json.sqlite3`（以及同資料夾的 `-wal`、`-shm` 檔，如果存在）下載保存。
  最穩的做法是先在面板停止應用，再複製檔案。
- 更新版本時：只替換 `src/`、`public/`、`package.json`，**不要動 `.env` 和資料庫檔案**，然後重新啟動。

## 6. 第一次使用

1. 用管理員帳號登入，到管理後台確認「系統狀態」沒有紅色警示。
2. 建議立刻到個人設定改成只有你知道的密碼。
3. 隱私權政策與使用條款在 `/privacy`、`/terms`，內容與經營者資訊請依你自己的單位修改後再對外開放
   （安裝包內是原開發單位的版本，不可直接沿用）。

## 7. 常見問題

- **啟動時顯示缺少 JWT_SECRET 或長度不足**：環境變數沒設定到，或少於 32 字元。
- **登入後馬上被登出**：網站沒走 HTTPS，或環境變數 `NODE_ENV` 與網址不一致；請確認網址是 https 且 `NODE_ENV=production`。
- **安裝相依套件時 better-sqlite3 失敗**：Node 版本太舊（要 22 以上），或主機無法下載預編譯檔；
  請改選 Node 22 後重新安裝，仍失敗就洽 Hostinger 客服，或改用 VPS。
- **忘記管理員密碼**：停止應用後，在應用根目錄執行
  `node scripts/reset-admin-password.mjs`（先設定好 `DB_PATH` 環境變數），依畫面輸入新密碼。
- **很多人同時註冊被擋「請求過於頻繁」**：`TRUST_PROXY` 設定不對（太小會讓所有人共用一個限流額度）。
