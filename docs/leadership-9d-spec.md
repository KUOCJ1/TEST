## 二、量表說明

### 作答標準（1–5 點）

| 分值 | 標籤 | 說明 |
|------|------|------|
| 1 | 非常不同意 | 幾乎從未如此 |
| 2 | 不太同意 | 偶爾如此，但非常態 |
| 3 | 普通 | 時有時無，難以判定 |
| 4 | 大致同意 | 多數時候如此 |
| 5 | 非常同意 | 幾乎總是如此 |

### 反向題計分說明

每構面含 2 題「反向計分題」（題目中以 🔄 標示），用以偵測作答一致性、降低社會期許偏誤。反向題的有效分數計算如下：

```
有效分數 = (量表最大值 + 量表最小值) − 原始作答分數
         = (5 + 1) − 原始分 = 6 − 原始分
```

**範例**：反向題作答「4（大致同意）」→ 有效分數 = 6 − 4 = **2**

## 五、計分邏輯

### Step 1：個別題目有效分數

```
正向題：有效分 = 原始作答分（1–5）
反向題：有效分 = 6 − 原始作答分（作答1→得5分；作答5→得1分）
```

### Step 2：子能力平均分

```
子能力平均 = Σ（該子能力所有題目的有效分）÷ 已作答題數
```

### Step 3：構面平均分

```
構面平均 = Σ（該構面所有題目的有效分）÷ 已作答題數
```

### Step 4：構面總分

```
構面總分 = Σ（該構面所有題目的有效分）
最大值 = 題目數 × 5；本系統每構面 10 題 → 最大 50 分
```

### Step 5：全量表總分

```
總分 = Σ（90 題所有有效分）
範圍：最低 90 分 ～ 最高 450 分
```

### 等級描述與建議

#### 🌱 領導探索期（90–225 分）
**描述**：您正處於領導力的起步階段，在部分構面已有初步的行為基礎，但整體表現仍有較大的成長空間。這是一個寶貴的覺察起點，了解自己目前的行為模式，有助於規劃更有針對性的學習路徑。

**行動建議**：建議從「溝通力」與「任務管理」這兩大基礎構面開始強化，培養清晰表達與有效規劃的日常習慣。找一位值得信任的導師，透過定期反思與回饋加速成長。

#### 📈 領導發展期（226–315 分）
**描述**：您已具備一定的領導行為基礎，並在多個構面展現出穩定的表現。但在高壓情境、跨部門協作或人才發展等進階領域，仍有提升空間。

**行動建議**：此階段最重要的是刻意練習「領導影響力」與「人才發展」，學習依據情境靈活調整領導風格，並主動建立回饋文化，幫助團隊持續成長。

#### 🚀 領導精熟期（316–405 分）
**描述**：您在大多數領導構面都有優秀的行為表現，能夠有效帶領團隊面對挑戰、激發潛能。您的決策品質與溝通能力已受到認可，也展現出培育他人的意願與能力。

**行動建議**：下一步是精煉「接班成熟度」與「思辨決策」能力，培養更宏觀的組織視野，並主動承擔更複雜的跨部門任務，以準備進入更高階的領導角色。

#### 👑 卓越領導者（406–450 分）
**描述**：您展現出卓越的全方位領導力！九大構面均有高度成熟的行為表現，不僅能帶動團隊、培育人才，更具備高度的自我覺察與組織承擔精神，是組織中不可多得的領導典範。

**行動建議**：以您的領導高度，建議聚焦於組織文化塑造與接班人培育，並將自身的領導智慧系統化，透過教練、輔導等方式影響更多人，持續擴大正向影響力。
