# 下半年 AI 課程需求調查 — 回覆分析指南

這份文件搭配獨立問卷 `public/volunteer-survey.html` 使用，說明如何把 Formspree
收到的回覆匯出，並交給 Claude 產出分析報告。

- 問卷網址（上線後）：<https://assess.rong-rise.com/volunteer-survey.html>
- 回覆收集：Formspree 表單 `xwvjgzvo`

---

## 第一步：匯出回覆

在 Formspree 後台打開該表單，擇一取得全部回覆：

- **方式 A（推薦）匯出 CSV**：點「Export / Download CSV」，下載 `.csv`（可用 Excel
  開啟，每列一位夥伴）。
- **方式 B　Google Sheets 連動**：若已設外掛，回覆會自動進試算表，直接使用該表。

> 免費方案每月收件數約 50 份，夥伴較多時留意額度，必要時當月升級。

---

## 第二步：交給 Claude 分析

最簡單方式 —— 用 **Claude.ai 網頁版 / 手機 App**：

1. 開新對話。
2. 把 CSV 檔**直接拖進 / 上傳**（Claude 看得懂 CSV / Excel）。
3. 貼上下方「分析提示語」。

也可把 CSV 放進本專案資料夾或貼給 Claude Code，由其直接算統計、做圖表、
產出排版好的報告（Markdown / 可印 PDF）。

---

## 分析提示語（可直接複製）

```
這是「AI 課程志工夥伴下半年需求調查」的回覆資料(CSV)。夥伴多為年長、
非 IT 背景。請幫我做一份淺顯易懂的分析報告,包含:

1. 整體概況:總回覆數、夥伴的 AI 熟悉程度分布
2. 上半年回顧:哪堂課最受好評、最多人想再深入、課程速度的反應
3. 下半年方向:想要「進階」還是「新領域」的比例
4. 最熱門的新主題排行(Q7),以及學習目的(Q9)
5. 上課方式偏好:形式、時長、最有幫助的輔助(Q10–Q12)
6. 開放意見(Q8、Q13)的重點整理與共同心聲
7. 最後給我 3–5 點「下半年課程規劃建議」

請用條列和表格呈現,語氣親切,並把每個重點配上對應的人數/百分比。
```
