# 新領導力評量：研究簡報與規劃討論稿

> 命名（2026-10-17 決定）：對外評測名稱為**雙環領導羅盤**（Dual-Loop Leadership Compass）；「快・永」「FastLast」僅為內部口訣／框架代稱。


> 狀態：**討論稿（v0.2）**，2026-10-17。已確認方向（見第 10 節），框架內容待訪談後成形。
> 目標：為榕耀人才永續顧問有限公司設計一套**自己的**領導力評量（框架＋題庫＋計分＋報告），
> 取代目前平台上的 L9D（經贏® 領導力九大構面行為評量），且**不能有抄襲嫌疑**。
>
> 證據標記：📎 = 這次有查到來源（見文末）；🧠 = 來自我既有知識、**引用前要回原始文獻核對**；⚠️ = 我沒能查證。

## 1. 一個必須先講清楚的現實

**「構面完全不同」在概念層面做不到，也不需要做到。** 任何領導力模型都會談到帶人、溝通、決策、變革、
自我覺察——這些是領導力這個領域本身的公共概念，不屬於任何一家公司。真正會構成抄襲爭議的是：

1. **題目的措辭**（受著作權保護；原創性才是門檻，不是努力程度）📎
2. **架構的「獨特表達」**：特定的構面命名、分類層級、子能力清單與排列、專有名詞與商標（例如「經贏®」「識己®」是註冊商標）
3. **整體「選擇、編排、組織」的相似度**：就算每個詞都換了，如果是同一份清單換同義詞，仍然會被認為是改寫

所以「不相似」的做法不是換名字，而是：**用不同的組織邏輯**切分領導力、**從自己的方法論與研究推導**構面、
**所有題目原創撰寫**，並且**留下可佐證的設計過程紀錄**。

## 2. 要避開的對照：L9D 現況（內部使用，僅供對照）

| 項目 | L9D 做法 |
|---|---|
| 組織邏輯 | **能力清單型**：9 個技能領域，分 3 層（個人基礎／人際協作／組織領導） |
| 9 大構面 | 溝通力、協作關係、任務管理、執行力、領導影響力、人才發展、思辨與決策、自我成長、接班成熟度 |
| 子能力 | 20 個（如聆聽他人、處理訊息、授權委責、分析判斷、世代協作與準備…） |
| 題目 | 90 題，每構面 10 題（含 2 題反向題），5 點同意度／頻率混合量表 |
| 計分 | 越高越好；總分 90–450，4 級落點；構面 5 級 |

**新框架要刻意避開的特徵**：同樣是「技能清單切 9 塊」、同樣的三層（基礎→人際→組織）排列、
「溝通／協作／任務／執行／影響／發展／決策／自我成長／接班」這組詞的組合、20 個子能力的切法、
「越高越好」的單一計分邏輯（可考慮改變）。

## 3. 公開的領導力研究地圖（作為靈感與邊界，不是抄寫來源）

| 模型 | 組織邏輯 | 測量工具與權利 | 證據 |
|---|---|---|---|
| Full Range Leadership（Bass & Avolio） | 以領導「風格」為軸：轉型型、交易型、放任型；轉型型含理想化影響、激勵動機、智力激發、個別關懷 | MLQ，商業授權（Mind Garden），**不可複製題目** | 🧠 |
| The Leadership Challenge（Kouzes & Posner） | 五項實踐：以身作則、共啟願景、挑戰現狀、使人行動、激勵人心 | LPI，商業工具，**不可複製題目** | 🧠 |
| Competing Values Framework | 兩條軸（彈性↔穩定、內部↔外部）形成四象限：合作、創造、競爭、控制 | 有多種問卷；概念框架可引用 | 📎（描述來自機構簡介，屬行銷性質） |
| Google Project Oxygen | 由績效資料與訪談歸納出的經理人行為：最初 8 項，2018 年擴充為 10 項（新增跨部門協作、決策） | 行為清單公開，量表為內部使用 | 📎 |
| 華人家長式領導（Cheng；Farh & Cheng 2000） | 三元素：**威權、仁慈、德行**；本土化架構，台灣有大量實證 | 學術量表，使用需引用並確認授權 | 📎（實證結果不一致：三個元素效果不同，威權對工作動機無顯著影響） |
| Servant／Authentic／Ethical／Adaptive／Situational Leadership | 各以「服務」「真誠」「倫理」「適應性挑戰」「情境」為核心 | 各有學術量表；多數需授權 | 🧠 |
| Korn Ferry、DDI、Hogan 等商業能力模型 | 大型能力清單或人格導向 | **專有、受保護** | 🧠 |

**一項近期質性研究的提醒** 📎：Chalmers 的研究分析 232 份得獎領導者的評價，發現傳統 FRLT 對「關係與發展面向」以及
「各面向之間的張力」著墨不足——這正是下面候選方案可以切入的空白，但它是質性研究、不是量表驗證，只能當線索。

**本土化機會**：台灣研究顯示 威權／仁慈／德行 的效果各不相同、不能混成「家長式」一個分數 📎——
這提示我們：**不要把領導力簡化成「越多越好」的單一加總**。

## 4. 原創性策略（要寫進專案流程）

1. **從自家方法論出發**：構面來自榕耀的顧問經驗與培訓內容（待你提供），再用上面的文獻做「交叉檢核」而不是「抄架構」。
2. **設計過程留紀錄（provenance log）**：每個構面、每一題記錄「想法來源、撰寫者、日期、參考文獻」。這是日後遇到爭議最有力的佐證。
3. **題目完全原創**：不拿任何商業量表的題目當種子，不改寫 L9D 的題目。題目從「具體行為情境」寫起，而不是從其他量表的句子換字。
4. **機械式相似度篩檢**：我可以寫一支腳本，把新題庫逐題與 L9D 的 90 題、以及你提供的任何其他參考題庫比對
   （字元／詞組重疊、近似度），超過門檻的題目一律重寫。這只能抓得到「我們手上有的題庫」，抓不到我看不到的別家題目。
5. **命名查詢**：新評量與構面的名稱先到經濟部智慧財產局商標檢索確認沒有衝突，避免 ® 商標問題。
6. **最後由 IP 律師過目**：我能做的是降低風險、保存證據，**不是法律意見**。

## 5. 三個候選框架（組織邏輯各不相同）

> 共同原則：維持與 L9D 不同的**切分方式**；每個方案都會用到公共概念（帶人、決策…），差別在於怎麼組織。

### 方案 A　「永續領導」——以「讓什麼持續」為軸（呼應「人才永續」）
領導 = 讓**成果、人、組織**在時間軸上可持續。不是列技能，而是問「領導者做了什麼讓這件事撐得久」。
- **成果可持續**：聚焦取捨（做什麼、不做什麼）、節奏與復原（產出與耗損的平衡）、復盤與學習
- **人可持續**：看見人（診斷每個人的狀態與潛力）、賦能與教練、信任與心理安全、接棒與傳承
- **組織可持續**：應變與調適、價值與榜樣、關係網絡（跨界與外部）
- 約 8 個構面。**優點**：品牌敘事與公司名稱一致；報告能講故事（哪一塊在「消耗」、哪一塊在「蓄積」）；計分仍是「越高越好」，與平台現有機制相容。
  **風險**：「人／事／組織」三分法太常見，要靠第二層切分與題目展現原創；部分構面（接棒與傳承）與 L9D 的「接班成熟度」概念接近，要特別設計。

### 方案 B　「領導時刻」——以「領導者面對的情境」為軸
以領導者反覆遇到的關鍵時刻切分：開局設期望、交辦、卡關與衝突、傳達壞消息、回饋、轉彎（變革／危機）、收斂決策、交棒。
- 題目是「**當…時，我會…**」的行為頻率題，天然具體、教練好用，與 L9D 的「能力清單」邏輯差異最大。
- **優點**：最不像技能清單；對課程設計與教練對話最直接。
  **風險**：情境題的內部一致性與構面獨立性較難驗證；情境之間重疊（卡關／衝突／壞消息）需要仔細切分；題目較長。

### 方案 C　「領導張力」——以「領導者要平衡的對立面」為軸
每個構面是一組張力：成果↔關係、穩定↔變革、授權↔掌控、近景↔遠景、堅持↔彈性、自信↔謙遜。
- 同時測量**兩端**，報告呈現「平衡／偏向／過度使用」，不是單一越高越好。與本土研究「不能只看加總」的發現一致。
- **優點**：計分邏輯與 L9D 根本不同、最能避免相似；診斷層次最豐富。
  **風險**：概念上近似 Competing Values 與 Polarity Management（要明確標示啟發來源並做出自己的版本）；
  「平衡」的常模與落點定義需要資料；現有平台的計分是「越高越好」，要增加新的計分模式（工程成本較高）。

### 我的建議（待你調整）
**以方案 A 為骨幹，吸收方案 C 的「張力」概念做第二層診斷**（例如「聚焦取捨」「賦能與掌控」兩個構面用雙端題呈現平衡）。
理由：A 與公司品牌一致、平台相容性高、能先上線；C 的張力元素讓報告有別於一般「分數越高越好」的清單型評量，
也最能拉開和 L9D 的差距。方案 B 的情境題可以當成**教練工作坊的延伸題庫**，不必放進核心量表。

## 6. 量表設計草案（可討論）

| 項目 | 建議 | 說明 |
|---|---|---|
| 構面數 | 8（依選定方案調整） | 與 L9D 的 9 不同，也方便雷達圖閱讀 |
| 每構面題數 | 6–8 題（共 48–64 題） | L9D 90 題偏長；48–64 題約 10–15 分鐘 |
| 題型 | **行為頻率題**（「過去三個月，我會…」），5 點：從不／很少／有時／經常／總是 | 頻率比同意度更貼近行為，也較不受自我感覺影響 |
| 反向題 | 少量（每構面 0–1 題）或改用「雙端題」 | 反向題可能降低信度也可能提高警覺，需在試測時檢驗 |
| 360° | 同一題庫，評分者版本改第三人稱 | 平台已支援 360° |
| 計分 | 構面平均（1–5）＋總分；方案 C 元素另算「平衡指標」 | 落點分級門檻先用理論值，**試測後用資料校正** |
| 報告 | 雷達圖＋構面敘事＋「消耗／蓄積」視角（方案 A）＋行動建議 | 沿用平台的敘事評語機制，內容全部原創 |

## 7. 驗證計畫（讓它是「評量」而不只是「問卷」）

1. **內容效度**：5–8 位資深教練／顧問獨立評估每題的相關性與清晰度，計算內容效度指標；
2. **認知預試**：8–10 位主管口頭回饋題目（看不看得懂、會不會誤解）；
3. **試測**：蒐集足夠樣本後做題目分析、信度（Cronbach's α）與因素分析，確認構面結構成立；⚠️ 樣本數與信度門檻的具體建議值，我這次**沒有查到可靠來源**，開工前需對照 DeVellis & Thorpe《Scale Development》第 5 版 📎 與 Hinkin（1995）、Clark & Watson（1995）原文；
4. **上線版本標示**：試測完成前標為「發展用 v0.9」，不得用於人事決策；
5. **常模與校正**：累積真實作答後，用平台既有的 benchmark 機制建立百分位與落點門檻。

## 10. 討論紀錄與已確認的決定（2026-10-17）

| # | 決定 | 影響 |
|---|---|---|
| D1 | 方法論來源：**有一些想法、尚未整理成文件** → 用訪談式討論，由我發問、你回答，再整理成構面草案 | 構面的原創性來自你們的實務經驗；訪談紀錄本身就是設計過程的佐證 |
| D2 | 框架方向：**A「永續領導」為骨幹，吸收 C「張力」元素做第二層診斷** | 計分仍相容現有平台；雙端題用於部分構面，「平衡指標」另算（實作時需評估工程量） |
| D3 | 用途與對象：**中高階主管發展與課前課後比較、接班人才盤點、企業客戶的組織診斷** | 見下方「用途帶來的設計要求」 |
| D4 | **自評與 360° 都是核心** | 每題要同時通順於第一人稱與第三人稱；360° 要有最少評分者數與匿名門檻 |

### 用途帶來的設計要求
- **接班人才盤點**屬於高風險用途：需要較嚴謹的效度證據（內容效度＋試測信效度），報告必須標示「不可作為單一決策依據」；
  並應包含與「潛力／學習敏捷」相關的行為面向（但不宣稱測到「潛力」本身）。
- **企業客戶的組織診斷**需要「團隊／組織層級的彙總報告」與**匿名保護**（例如某個群組評分者少於 3 位就不顯示分項），
  並且客戶端的個人資料處理要在隱私權政策與合約中講清楚（目前政策只涵蓋一般學員使用）。
- **中高階主管**：題目要寫「策略層次與跨部門」的行為，不是基層主管的任務管理；難度與情境要符合。
- **360° 雙人稱**：題目避免只有第一人稱才說得通的句子（如「我覺得…」），改寫成可觀察的行為。
