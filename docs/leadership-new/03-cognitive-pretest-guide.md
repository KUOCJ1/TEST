# 認知前測訪談指引（v0.1）

目的：在大規模試測之前，確認「受測者讀到的意思」和「我們想問的意思」是否一致，找出看不懂、多義、雙重、不適用或社會期許過強的題目。這一步不看分數，看理解。

## 1. 受訪者

- 人數：每輪 5–8 位，修題後可再做第二輪（⚠️ 這是常見做法，非本案查證的標準，以題目問題是否收斂為準）。
- 組成（盡量涵蓋）：
  - 中高階主管 3–4 位（不同產業、至少 1 位來自中小型或家族企業）
  - 曾被主管評量過的部屬或同儕 2–3 位（用來測他評版）
  - 世代多元：至少含 1 位 35 歲以下、1 位 50 歲以上
  - 至少 1 位平常工作上常用 AI 工具、1 位很少用（測人機題是否預設太多）
- 排除：參與過本題庫設計的人、與我們有直接業務往來而不便說真話的人。

## 2. 事前準備與告知

- 這是在測題目，不是在測受訪者。請在開場說明。
- 取得口頭或書面同意；不蒐集姓名之外的可識別資料，紀錄只用代號（P1、P2…）。
- 錄音需另行徵求同意；不錄音時以紀錄表手寫即可。
- 訪談資料只用於修題，不放進評量平台，也不對外提供。

## 3. 流程（每人約 60 分鐘）

| 階段 | 時間 | 內容 |
|---|---|---|
| 開場 | 5 分 | 說明目的、告知可隨時停止、示範一題「出聲思考」 |
| 量表理解 | 5 分 | 先看頻率量表（從不／很少／有時／經常／總是），問「經常」大概是多常？ |
| 逐題訪談 | 40 分 | 每人讀一組題（約 23 題）；先自己作答，再回答追問 |
| 整體回饋 | 10 分 | 題目整體感受、哪些題最難答、哪些最不像真實職場 |

## 4. 逐題的追問（至少問一種，有疑慮就多問）

1. **複述**：「這題你覺得在問什麼？用你自己的話說一遍。」
2. **舉例**：「你想到的是哪一次的情境？」（確認想到的是行為而不是一般態度）
3. **頻率判斷**：「你選這個頻率，是怎麼決定的？」
4. **關鍵詞**：「『{題中關鍵詞，例如 決策範圍、復盤、人機配置}』對你來說是什麼意思？」
5. **作答難度**：「有哪個部分讓你猶豫嗎？是不是同時問了兩件事？」
6. **社會期許**：「如果是你的主管，你會覺得被問這題誠實回答容易嗎？」
7. **他評版專用**：「你有機會看到這個行為嗎？看不到時你會怎麼作答？」（驗證『無法判斷』選項）
8. **用語**：「這句話在你的職場上會這樣說嗎？你會怎麼說？」

追問原則：不引導（不說「是不是在問…」）；先讓對方說，再補問；沉默不要急著替對方說完。

## 5. 問題代碼（紀錄表用）

| 代碼 | 意思 | 例 |
|---|---|---|
| A | 看不懂／用語陌生 | 不清楚「復盤」是什麼 |
| B | 多義：不同人讀出不同意思 | 「決策範圍」被理解成權限或預算 |
| C | 雙重：一題問了兩件事 | 同時問「說明」和「檢討」 |
| D | 不適用：自己的情境沒有這件事 | 沒有部屬的主管 |
| E | 社會期許強：明顯只有一種好答案 | 「出了問題我先找人負責」 |
| F | 用語不自然／不像台灣職場說法 | |
| G | 太抽象：想不到具體情境 | |
| H | 無法觀察（他評版） | 想不出看過哪些證據 |
| I | 量表問題：頻率不好選 | 「很少」與「有時」界線不明 |

## 6. 判定修題的規則

- 同一題在同一輪出現 **2 位以上** 的 A／B／C／G：必改。
- 只 1 位出現：記錄，看第二輪是否重現。
- 同一題 D 代碼 ≥ 2：考慮改成不預設情境的說法，或標註『不適用』選項。
- E 代碼的題目：評估是否改成「兩難」寫法，或接受它（反向題本來就偏社會期許）。
- 他評版 H 代碼 ≥ 2：該題 `observability` 標為 low，並確認有『無法判斷』選項。
- 每次修改要寫進題目檔的修訂紀錄（日期、版本、理由），並重跑相似度檢查。

## 7. 題組分配（每人讀一組；構面均勻分散）

反向題、人機題、張力題都跨組分布，避免單組偏重。受訪者請從 1–3 組輪流分配；他評版另請 2–3 位部屬或同儕讀自己看過的主管版本。

## 8. 紀錄表欄位（每位受訪者一張）

受訪者代號｜角色｜世代｜組別｜題號｜複述是否符合原意（是／部分／否）｜問題代碼｜原話摘錄｜建議修法｜是否需第二輪

## 9. 收斂與下一步

1. 訪談後 2 日內整理紀錄表，彙整成「題目 × 問題代碼」矩陣。
2. 依第 6 節規則修題，產出 v0.3；第二輪只測修改過的題，加上 5 題未改的作對照。
3. 通過後才進入專家內容效度審題（已備有審題表）與試測。
4. 建議順序：認知前測 → 專家審題 → 試測。前測先清掉明顯的問題，專家才不會把時間花在看不懂的題目上。
