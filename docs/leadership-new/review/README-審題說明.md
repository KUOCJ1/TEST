# 專家審題說明（給審題專家）

感謝協助。請對 `expert-review-sheet.csv` 的每一題打分。共 69 題，約需 40–60 分鐘。

## 背景
這是一份新的領導力行為評量，用「頻率」作答（從不 → 總是），分自評版與他評版（360°）。八個構面分兩環：
- 快環：洞察情勢、聚焦應變、知人授權、凝聚帶動
- 慢環：敏捷學習、穩定當責、識才育才、傳承留能

「張力」標記的題目成對出現（例如聚焦↔彈性），目的是看兩端是否平衡，不是越高越好。反向題（標記「反向題」）是故意用相反方向寫的，用來偵測隨便作答，不需要你修改它的方向。

## 請填寫的欄位
| 欄位 | 填法 |
|---|---|
| 相關性 | 這題與所屬構面／子面向有多相關？ 1 = 完全無關　2 = 略有關　3 = 相當相關　4 = 非常相關 |
| 清晰度 | 這題是否清楚、不會有兩種以上讀法、不含兩件事？ 1 = 看不懂　2 = 需修改才清楚　3 = 大致清楚　4 = 非常清楚 |
| 像他牌題目? | 你是否在其他領導力測評或書籍中看過非常相似的題目？是／否／不確定。若是，請在備註寫出來源。 |
| 修改建議／備註 | 任何建議。特別歡迎指出：用語在台灣職場是否自然、是否有世代或層級的偏誤。 |

## 另外請你留意
- 一題只問一件事。若發現雙重問題請標出。
- 他評版的措辭是系統轉換出來的，請檢查是否通順。
- 不需要評分「這個領導行為是否重要」，只評題目與構面的契合度。

## 後續（內部）
相關性評分 3–4 分的專家比例為該題內容效度指標（I-CVI）。常見經驗法則是專家人數 6 位以上時要求 ≥ 0.78，人數少則更嚴格；此門檻 ⚠️ 引自一般量表發展文獻，採用前應再對照原始出處。
