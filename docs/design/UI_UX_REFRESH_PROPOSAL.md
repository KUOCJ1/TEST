# 經贏評測｜UI/UX 改版建議書 v1（榕光 Banyan Glow）

日期：2026-11-13　｜　視覺樣張：[`ui-refresh-mockups.html`](ui-refresh-mockups.html)（用瀏覽器開，含設計系統＋3 個手機畫面＋教練桌機畫面）

> 本建議書只是設計提案，**沒有動任何正式程式**。已確認的前提：學員手機優先、教練桌機為主；品牌感受要「溫暖、教育成長」；A4 列印報告版面不動；字型用開源中文字型。

## 1. 結論（先講重點）

1. **方向：榕光（Banyan Glow）**。品牌「榕耀」的「榕」是榕樹、「耀」是光，直接轉成視覺語言：**深榕綠＋暖陽金＋暖紙底**。學員看到的是「你正在長成什麼樣的樹」，不是冷冰冰的分數。
2. **不採用 UI/UX Pro Max 自動推薦的「Claymorphism＋Baloo 2／Comic Neue」**。那是兒童／休閒遊戲風格，放在企業領導力評測、HR 決策者面前會被當成玩具。我只借用它的檢核規則（對比、觸控、無障礙），風格由品牌與使用者決定。
3. **最大的視覺問題是「全部是褐色」**：墨、暖灰、銅金三個色相太接近，層次全靠明度硬撐，所以整個介面看起來沉、舊。改成「綠＋金」兩個清楚的色相，其餘為中性。
4. **分三階段上線**：先換 token（一天內可看到全站變化）→ 再重做學員三屏 → 最後教練後台與深色模式。每階段都能單獨上線、單獨回退。

## 2. 現況診斷（依 UI/UX Pro Max 的優先順序）

| 優先 | 問題 | 位置 | 影響 |
|---|---|---|---|
| 無障礙 | 為了過對比，把 `slate-400/500`、`emerald-600`、`amber-600` 逐一調深，導致整體灰褐、層次變弱 | `tailwind.config.js` | 看起來悶，且之後每加一個色都要重調 |
| 風格一致 | 圓角混用（按鈕 `rounded-sm`、卡片 `rounded-md/xl/2xl`）；`.card`／`.panel`／`.panel-primary`／`.panel-secondary` 四種卡片；舊紫色 `brand` 色階仍殘留 | `index.css`、各元件 | 同一頁面像多個產品拼起來 |
| 圖示 | 用 emoji 當圖示：落點徽章（🚀 等）、報告按鈕（🖨️） | 題庫設定、報告工具列 | 不同平台長相不同，不夠專業（規則：用 SVG 不用 emoji） |
| 學員流程 | 首頁資訊多、主行動不明確；作答是 48 題長清單；結果頁的主角是「分數」而不是「你在哪個階段、下一步做什麼」 | `AppShell`、`SurveyApp`、`ResultPanel` | 學員看完不知道該做什麼 |
| 色彩邏輯 | 「待加強」用琥珀、錯誤用紅，與「落點等級」四色混在一起，語意重疊 | 全站 | 學員會把「發展期」當成警告 |
| 深色模式 | 靠 `index.css` 上百行 `!important` 全域覆寫 | `index.css`、`dark-status.css` | 脆弱、每改一個色都可能破 |
| 排版 | 只有 Noto Sans TC，宋體僅零星使用；標題都是粗黑體 | 全站 | 缺少溫度與編輯感，也缺少層級對比 |

## 3. 設計系統（精簡版）

### 3.1 色彩（全部通過 WCAG AA）

| Token | 色碼 | 用途 | 對比 |
|---|---|---|---|
| `banyan` 榕綠 | `#1F5D4A` | 主色、主要按鈕、選取狀態 | 白字 7.7:1 |
| `banyan-50` | `#E4F0E6` | 強項、已完成、淡底 | 與榕綠字 6.6:1 |
| `sun` 暖陽 | `#F2B544` | 點綴、進度、重點 CTA | 墨字 8.2:1 |
| `sun-50`／`sun-text` | `#FCEFD3`／`#8A5200` | 優先成長、提示 | 6.0:1 |
| `clay` 陶土 | `#A8452D` | 錯誤／警示（取代刺眼紅） | 紙底 5.5:1 |
| `paper` 暖紙 | `#FBF7EF` | 頁面底色 | — |
| `ink` 墨 | `#1F2924` | 內文、深色區塊 | 14:1 |
| `muted` | `#5B6760` | 次要文字 | 白底 5.9:1、紙底 5.5:1 |

**語意規則**：綠＝已具備／完成／主要行動；金＝成長機會／重點；陶土＝只用在真正的錯誤與未完成。「發展期」是成長階段，不是警告。

**落點等級＝成長階段**（取代 emoji）：探索期（種子，金淡）→ 發展期（萌芽，綠淡）→ 精熟期（成樹，榕綠實心）→ 卓越（森林，墨底金字）。圖示統一用 SVG 葉片（Lucide `leaf`／`sprout`／`trees`）。

### 3.2 字型（皆開源，符合全域規範）

- 標題、大數字：**Noto Serif TC**（思源宋體）600–700，數字用 `tabular-nums`。
- 內文、介面：**Noto Sans TC**（思源黑體）400／500／600，基本字級 16px、行高 1.6。
- 嵌入方式：HTML 走 Google Fonts；PDF 報告維持現狀（不動）。

### 3.3 形狀、陰影、動態

- 圓角：按鈕／輸入 12px、卡片 14px、大區塊 20px；徽章全圓角。統一三級，不再混用。
- 陰影：一種淡陰影（卡片）＋一種按鈕陰影（主要按鈕），不疊多層。
- 觸控：所有可點元素 ≥44px（已由手機 App 化 M1 落實）。
- 動態：150–300ms；按壓縮放 0.98；結果頁環形圖進場 600ms；全部尊重 `prefers-reduced-motion`。
- 卡片合併：`.card`／`.panel`／`.panel-primary`／`.panel-secondary` 合併為 `surface`（預設）與 `surface-hero`（重點）兩種。

### 3.4 元件原則

- 一個畫面只有一個主要按鈕（榕綠實心）；次要＝白底綠框；再次要＝文字鈕；重點 CTA（如「開始複測」）才用暖陽金。
- 表單：標籤永遠可見（不只 placeholder）、錯誤顯示在欄位旁、輸入框高度 44px。
- 導覽：手機底部導覽 ≤5 項，選中態用「淡綠膠囊＋圖示加粗」；桌機教練改左側固定導覽（取代頂部分頁列）。

## 4. 三個關鍵畫面（樣張已做）

1. **學員首頁**：「嗨，大明，繼續長高吧」＋一張「下一步」主卡（榕綠底、金色 CTA）＋班級卡＋評量卡。每屏只有一個主行動。
2. **作答**：頂部細進度條＋「12 / 48 題」；章節標題帶預估剩餘時間；選項是 5 個大圓角按鈕（選中＝榕綠＋陰影）；浮動「還有 36 題，跳到下一題」。
3. **結果**：環形圖（榕綠）＋成長階段徽章＋一句人話（「你已經長出穩定的枝幹」）＋四段階段條；強項／優先成長兩張小卡；構面條圖；底部固定「查看完整分析」。
4. **教練桌機**：左側深色導覽、頂部班級切換＋兩個主要動作、第一排四個數字（完成率為主）、構面條圖＋成員表（階段徽章、評語狀態）。

## 5. 實作路線（建議分階段，各自可上線與回退）

| 階段 | 內容 | 範圍 | 風險 |
|---|---|---|---|
| **D1 Token 換色** | `tailwind.config.js` 把 `ink/paper/brass/slate` 重新對映到榕綠／暖陽／暖紙；刪除舊紫色 `brand`；統一圓角與陰影 token；Noto Serif TC 標題 | 全站一次變色，不改版型 | 既有 `.dark` 覆寫要同步；e2e、axe 對比測試要重跑 |
| **D2 共用元件** | 按鈕、卡片、徽章、輸入、導覽、進度；落點徽章換 SVG；合併卡片類別 | `index.css` 與共用元件 | 中：很多頁面用到，要逐頁看過 |
| **D3 學員三屏** | 首頁、作答、結果的版型與文案（含環形圖、成長階段條） | `AppShell`、`SurveyApp`、`ResultPanel` | 中：e2e 黃金路徑與 `mobile-layout` 測試要更新 |
| **D4 教練與管理** | 左側導覽、KPI 列、成員表；管理後台沿用元件 | `coach/`、`admin/` | 中：桌機版面會變（你已同意改版） |
| **D5 深色模式** | 以 CSS 變數重寫，砍掉大量 `!important` 覆寫 | `index.css`、`dark-status.css` | 高：最後做、可獨立延後 |
| **不動** | A4 列印報告（`printable-report/`、各 Printable 元件）、計分與題庫結構 | — | — |

估時（含測試與修 e2e）：D1 約 0.5–1 天、D2 約 1–1.5 天、D3 約 1.5–2 天、D4 約 1.5–2 天、D5 約 1–1.5 天。

## 6. 反向觀點與風險

- **品牌一致性**：既有「經贏®」對外簡報、提案、PDF 報告若是墨色＋銅金，改成榕綠後，平台與其他交付物會不一致。若要統一，報告封面色與簡報模板也得跟著調（本次說好不動報告）。建議確認「榕綠」是否就是你要的品牌主色，再往下做。
- **「溫暖成長」過頭的風險**：用樹／葉片隱喻很討喜，但對高階主管學員可能顯得稚氣。樣張已用宋體標題、克制的插圖（只有葉片圖示與環形圖，沒有卡通）來壓住；若客戶偏嚴肅，可把階段名稱換成中性字（「探索／發展／精熟／卓越」已是中性）、拿掉「繼續長高吧」這類口語。
- **色彩無障礙**：綠與金對部分色覺異常者區分度有限，所以階段徽章同時有文字與圖示，進度條也有百分比數字，不靠顏色單獨傳達意義。
- **工程成本**：D1 看起來「一天就變了」，但 D2–D5 才是真正的設計感來源，不要只做 D1 就停——只換色不改版型會顯得「換皮」。

## 7. 需要你決定

1. 主色是否採用**榕綠 `#1F5D4A`**（與既有銅金／墨色的品牌資產是否衝突）？
2. 落點階段名稱沿用「探索期／發展期／精熟期／卓越」並以葉片圖示呈現，OK 嗎？
3. 教練桌機改**左側導覽**，可以接受嗎（桌機版面會變）？
4. 先做 **D1＋D3（學員三屏）** 還是照 D1→D5 全做？（建議先 D1＋D3，讓學員先感受到改變，再決定要不要往教練端推。）
